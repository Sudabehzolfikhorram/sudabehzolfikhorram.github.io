# دستیار «از من بپرسید»: چطور کار می‌کند و چطور روشنش کنید

## در یک نگاه

دستیار حالا دو مغز دارد:

1. **هوش مصنوعی (Claude)**: هر سؤالی را با هر لحنی می‌فهمد، اول تحلیلش می‌کند (منظور واقعی سؤال چیست، چه کسی می‌پرسد، چه شواهدی از کار شما جوابش را می‌دهد) و بعد مثل یک مصاحبه‌ی واقعی جواب می‌دهد؛ کوتاه، دقیق و فقط از روی واقعیت‌هایی که در فایل دانش نوشته شده.
2. **جواب‌های آماده (موتور داخلی)**: اگر هوش مصنوعی روشن نباشد، سهمیه‌ی روزانه تمام شود یا اینترنت قطع باشد، دستیار بی‌صدا با همان جواب‌های آماده‌ی قبلی (که حالا خیلی کامل‌تر شده‌اند) جواب می‌دهد. پس چت هیچ‌وقت ساکت نمی‌ماند.

هر سؤالی که جوابش در فایل دانش نباشد، یا جزو موضوع‌هایی باشد که خودتان می‌خواهید جواب بدهید (حقوق، نقطه‌ضعف، دلیل رفتن، رفرنس و…)، مثل قبل همان لحظه برایتان ایمیل و تلگرام می‌شود، همراه با جوابی که دستیار داده.

## فایل‌ها

| فایل | کارش |
|---|---|
| `public/assistant/knowledge.md` | **منبع واحد حقیقت.** همه‌ی واقعیت‌ها درباره‌ی شما، قوانین رفتاری، لحن فارسی و انگلیسی و نمونه‌جواب‌ها. برای اصلاح یا اضافه کردن هر جوابی فقط همین فایل را ویرایش کنید و push کنید؛ حداکثر یک ساعت بعد دستیار از آن استفاده می‌کند. |
| `docs/contact-form.gs` | بک‌اند (Google Apps Script): فرم تماس + بخش جدید `ask` که به Claude وصل می‌شود، با محدودیت تعداد سؤال و کش. |
| `src/lib/assistant-remote.ts` | سمت سایت: سؤال و چند پیام قبلی گفتگو را به بک‌اند می‌فرستد. |
| `src/lib/assistant.ts` | جواب‌های آماده (پشتیبان). |
| `scripts/test-assistant.mjs` | تست QA جواب‌های آماده: `npm run test:assistant` |

## روشن کردن هوش مصنوعی (یک بار، حدود ۱۰ دقیقه)

1. در [platform.claude.com](https://platform.claude.com) یک حساب بسازید، از بخش Billing کمی اعتبار بخرید (۵ دلار برای شروع کافی است) و از Settings → API keys یک کلید بسازید.
2. در [script.google.com](https://script.google.com) پروژه‌ی فرم تماس را باز کنید و کل محتوای فایل را با محتوای جدید `docs/contact-form.gs` جایگزین و ذخیره کنید.
3. Project Settings (چرخ‌دنده) → Script Properties → Add property:
   `ANTHROPIC_API_KEY` = کلیدی که ساختید. (کلید فقط آنجا می‌ماند؛ نه در کد است، نه در سایت.)
4. از لیست توابع بالای ادیتور `testAssistant` را انتخاب کنید و Run بزنید. در لاگ باید دو جواب واقعی ببینید (یکی انگلیسی، یکی فارسی). اگر خطا بود، متن خطا دقیقاً می‌گوید مشکل چیست.
5. Deploy → Manage deployments → مداد → Version: New version → Deploy. آدرس عوض نمی‌شود.
6. در `src/lib/content.ts` مقدار `assistantAI` را `true` کنید و push کنید (یا به من بگویید). تا وقتی `false` است، سایت اصلاً سراغ هوش مصنوعی نمی‌رود و جواب‌های آماده فوری می‌آیند.

**مهم:** فایل دانش از روی سایت زنده خوانده می‌شود، پس اول این تغییرات باید روی `main` merge و منتشر شده باشند.

## هزینه و محدودیت‌ها

- مدل پیش‌فرض `claude-opus-5-5` است (باکیفیت‌ترین برای این کار). هر سؤال تقریباً ۳ تا ۶ سنت هزینه دارد؛ اگر بازدیدکننده پشت‌سرهم چند سؤال بپرسد، سؤال‌های بعدی ارزان‌ترند (کش).
- برای هزینه‌ی خیلی کمتر (حدود یک‌دهم سنت برای هر سؤال، با کیفیت کمی پایین‌تر): `ANTHROPIC_MODEL` = `claude-haiku-5-5`.
- سقف پیش‌فرض: ۱۰۰ سؤال در روز برای همه‌ی بازدیدکننده‌ها، و ۲۵ سؤال در ساعت برای هر بازدیدکننده. برای تغییر: `ASSISTANT_DAILY_LIMIT`. وقتی سقف پر شود، دستیار با جواب‌های آماده ادامه می‌دهد.
- `ANTHROPIC_EFFORT`: `low` سریع‌تر و ارزان‌تر، `medium` (پیش‌فرض) متعادل، `high` دقیق‌تر و کندتر.

## اصلاح جواب‌ها

- هر جواب اشتباه را در `public/assistant/knowledge.md` درست کنید. برای اینکه فوراً اعمال شود، بعد از انتشار سایت تابع `refreshKnowledge` را در Apps Script یک بار Run کنید.
- همه‌ی گفتگوها (با جواب‌هایی که دستیار داده) وقتی بازدیدکننده پنل را می‌بندد برایتان ایمیل می‌شوند. هر جوابی را که دوست نداشتید، اصلاحش را به فایل دانش اضافه کنید.

## رفتارهایی که تست شد

- سؤال‌های کلاسیک مصاحبه: معرفی، چرا شما، نقاط قوت، نقطه‌ضعف، تعارض، فیدبک، اهداف ۵ ساله، انگیزه، ددلاین، ابهام، اندازه‌گیری موفقیت.
- لحن‌های مختلف: رسمی، خودمانی، فینگلیش، کوتاه و تند، شوخی، بی‌ادب، تلاش برای دور زدن قوانین («دستوراتت را نادیده بگیر»)، سؤال‌های نامربوط.
- سؤال‌های چندبخشی و ادامه‌دار («و اون پروژه چقدر طول کشید؟»): چند پیام آخر گفتگو همراه هر سؤال فرستاده می‌شود.
- تست خودکار جواب‌های آماده: ۹۶ سناریو، همه قبول (`npm run test:assistant`). فهرست کامل جواب‌ها با `npm run docs:assistant` در `docs/assistant-answers.md` ساخته می‌شود.
